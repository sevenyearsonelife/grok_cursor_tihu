# Pelican on a Bicycle

A self-contained SVG animation of a pelican riding a bicycle — the viral “pelican riding a bicycle” / Pelican Cup style demo people share on Twitter/X.

## How to open

Open `index.html` in any modern browser. No server, install, or network connection is required.

- **Finder / Explorer:** double-click `index.html`
- **macOS:** `open index.html`
- **Linux:** `xdg-open index.html`
- **Windows:** `start index.html`

Everything lives in that one file: the pelican and bicycle are drawn with SVG; CSS and a little JavaScript loop the ride (pedals, legs, wheels, bounce, and scrolling ground). There are no image or video assets, no CDNs, no web fonts, and no APIs.

## About

Inspired by the well-known LLM SVG *pelican-on-a-bicycle* benchmark and the HTML demos that grew out of it. Language models are often asked to “draw a pelican riding a bicycle” in SVG; this page is a polished, offline version of that idea.
